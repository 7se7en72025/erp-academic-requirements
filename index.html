ERP Registration Walkthrough

Registration day moves fast, and the portal is not exactly friendly the first time you meet it. This is a click-through copy of the screens you will go through, with made-up courses, so you can get lost in it now instead of during your slot.

What you can do here
  • Walk the whole flow yourself, from the homepage to a finished timetable.
  • Watch it play itself through, if you would rather just see the shape of it.
  • Get a clash wrong on purpose and see what the Validate screen actually says.
Start the walkthrough Play it automatically
The route it takes
  1. Student Homepage → the Registration tile
  2. My Academic Requirements → pick a course
  3. Course Detail → Show Sections → select a section
  4. Related Class Sections, if the course also needs a tutorial or a lab
  5. Enrollment Preferences → the course lands in your cart
  6. Repeat for the rest, then open the Enrollment Shopping Cart
  7. Validate → Enroll → My Class Schedule
Worth knowing
  • Refreshing any page restarts the walkthrough with an empty cart. Ctrl+X does the same on purpose.
  • Some sections are marked Closed and cannot be picked, because the real one does that too.
  • Every instructor name here is invented, and so is every class number, room, timing and exam date. Any resemblance to actual faculty is accidental — this is not the real section list.
What this is not

It is not a source of truth for anything. The class numbers, rooms, timings and exam dates were invented to make the screens look plausible. For the actual sections, check the ERP itself and the official timetable PDF; for the actual rules and dates, check the current notices on academic.bits-pilani.ac.in.

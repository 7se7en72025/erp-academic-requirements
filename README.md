# ERP Registration Walkthrough (static replica)

A static, multi-page recreation of the BITS ERP (PeopleSoft) student portal registration
flow, styled after the real portal's sidebar/header chrome. Built for the freshers'
registration walkthrough guide — all names, grades, and instructors are placeholders,
not real data.

## Pages

- `index.html` — the landing page explaining what this is
- `student-homepage.html` — the tile wall you sign in to
- `academic-requirements.html` — My Academic Requirements (course requirement tree)
- `course-detail.html?course=<ID>` — course detail, section picker, add-to-cart flow
  (IDs: CHEMF110, CHEMF111, EEEF111, MATHF111, MEF112, PHYF110, PHYF111)
- `related-sections.html` / `enrollment-preferences.html` — the two screens between
  picking a section and the course landing in the cart
- `shopping-cart.html` — Enrollment Shopping Cart
- `validate-results.html` / `enroll-results.html` — the 3-step wizard
- `weekly-schedule.html` — My Weekly Schedule (built from enrolled courses)

## Layout

Every page is a shell: a `<div id="chrome-root">` and a list of scripts. All the
markup is generated by the modules under `assets/js/`, which load in dependency
order — each captures the previous ones' exports as it runs, so the order in the
page is load-bearing:

```
dom → catalog → store → schedule → components → chrome → pages/<page> → demo
```

- `catalog.js` — the course catalogue, program structure and student identity
- `store.js` — cart / enrolled / in-progress selection, in `localStorage`
- `components.js` — the shared page furniture (id row, tabs, grids, legends)
- `chrome.js` — the gradient rule, header bar and sidebar
- `assets/css/erp.css` — all styling
- `assets/img/` — the portal's own icons, copied out of a saved page

## Aesthetics

Colours and metrics are taken from the real portal's own stylesheets rather than
eyeballed: the Fluid chrome from `PSSTYLEDEF_FMODE` / `PTNUI_LANDING_CSS` /
`PTGP_GUIDED_PROCESS_CSS`, and the classic content area from
`PSSTYLEDEF_TANGERINE`. The two families are deliberately distinct — the chrome
is Fluid blue (`#246FC7`), the page body classic navy (`#004b91`) with tangerine
headings (`#ab5b1a`).

**The section data is made up.** Class numbers, timings, rooms and exam dates are
illustrative, and the instructor names are invented — any resemblance to actual
faculty is accidental. This is not the live timetable; check the real ERP and the
official timetable PDF for actual sections.

Refreshing any page clears the cart and enrolled classes, so the flow can be demoed
again from the start; Ctrl+X does the same on purpose.

## Flow

Student Homepage → Registration tile → My Academic Requirements → click a course →
Course Detail → Show Sections → Select a section (repeat if a second component like
a Tutorial/Lab is required) → Next → added to cart (confirmation modal) → Return to
My Academic Requirements → repeat for remaining courses → Enrollment Shopping Cart →
Validate → View Results → My Weekly Schedule.

## Run

```
python3 -m http.server 8000
```

then visit http://localhost:8000/student-homepage.html

## Autoplay walkthrough (for screen recording)

http://localhost:8000/student-homepage.html?demo=1

Drives the entire flow on its own — all seven courses into the cart, then
Validate → Enroll → weekly timetable — with an on-screen cursor that travels
to each control and shows a click ripple. Built to be screen-recorded; add
narration afterwards.

- `?demo=1&speed=0.7` — slower (any multiplier; `2` is double speed)
- `?demo=1&caption=0` — hide the caption bar, cursor only
- `Escape` — stop a run partway
- `Ctrl+X` — clear cart/enrolled state

The run always resets state first, so it starts from empty every time. It
picks only open sections, and the combination has no meeting-time clashes,
so Validate reports every course as OK to Add.

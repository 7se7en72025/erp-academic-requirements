# ERP — My Academic Requirements (static replica)

A static HTML/CSS/JS recreation of the BITS ERP (PeopleSoft) **My Academics → My Academic Requirements** page,
for use in the freshers' registration walkthrough.

## Files
- `index.html` — page markup
- `styles.css` — PeopleSoft-like styling
- `script.js` — Expand All / Collapse All and per-section toggles

## Run
Open `index.html` in a browser, or:

```
python3 -m http.server 8000
```

then visit http://localhost:8000
